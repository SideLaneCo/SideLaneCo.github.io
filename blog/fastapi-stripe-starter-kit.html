We Found a Real Stripe SDK Bug Building Our Own SaaS. Here's the Fix, Pre-Built.

Side Lane Co

Before you write a single line of the feature that actually makes your SaaS different, you have to build the part that makes it a SaaS at all: accounts, password hashing, a free tier that actually gates something, a paid tier that unlocks it, and Stripe wired up correctly on both ends. None of that is your product. All of it has to exist before your product can charge anyone a dollar.

We didn't design this cold

This scaffold isn't a tutorial project. It's the actual auth and billing layer we built for RehabRunway, a real SaaS with real Stripe billing live in production, pulled out and generalized so another developer doesn't have to rebuild the same boring 20% before they can start on their own 80%.

Along the way we hit a real bug: a breaking change in a newer version of the official stripe-python SDK where StripeObject stopped behaving like a dictionary, so the standard .get() pattern webhook handlers usually use just silently stopped working. Every webhook returned a 500. We found it from a real production traceback, not a guess, and fixed it with the SDK's actual supported method, .to_dict(). That fix is already in this kit. You don't have to lose the afternoon we lost finding it.

What's actually in it

Session-cookie auth with bcrypt password hashing, a free tier that genuinely blocks access past its limit instead of just displaying a banner, Stripe Checkout wired to a webhook that unlocks the paid tier the moment payment succeeds, and the subscription-cancellation path that locks it back down. Built on FastAPI. Tested end to end: register, hit the free-tier wall, check out, get unlocked, cancel, get locked out again.

What it isn't

Here's the honest part. This is a lean, single-tenant scaffold, not a fully-loaded platform. It doesn't have team accounts, OAuth login, or background job queues. If you need all of that out of the box, there are more expensive, more built-out commercial starter kits that include it. What this has is the one piece every one of those kits also needs and none of them can prove actually works in production, because this one already does.
